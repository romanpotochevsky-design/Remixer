# Cloud — стенд и замеры (22.09.2026)

- `shot.mjs` — открывает билдер, жмёт Cloud в рейле, снимает окно и печатает крупные боксы.
- `measure.mjs` — полный замер против борда `30816:49569`: окно, меню, шапка, колонки, ряды,
  скроллбар, длина прокрутки.
- `rail.mjs` — три состояния кнопок рейла (покой · ховер · выбрано) → `rail-states.png`.
- `cloud-window.png` — окно целиком на 1600×900.

Запуск: `CHROME=/opt/pw-browsers/chromium-1194/chrome-linux/chrome node scratchpad/cloud/<файл>`
при поднятом `npx vite --port 5174` (или `BASE=http://localhost:4173` на сборке).
