# Measured design tokens — AI website builders
Snapshot: 13 Aug 2026, read from live computed styles / CSSOM (not from articles).
Method: in-app browser at 1440×900, `getComputedStyle` sweep over every text node + `:root` custom-property dump.

## 1. Lovable — lovable.dev

**Typeface:** `Camera Plain Variable` (licensed variable grotesk — NOT Inter). Fallback ui-sans-serif.
**Page bg:** `#FAFAFA`. Marketing site is LIGHT, not dark.

### Type scale (measured)
| px | weight | line-height | tracking | ratio |
|---|---|---|---|---|
| 48 | 600 | 52.8 | −1.92px | lh 1.10 · ls −0.040em |
| 48 | **480** | 52.8 | −1.44px | lh 1.10 · ls −0.030em |
| 36 | 600 | 39.6 | −1.44px | lh 1.10 · ls −0.040em |
| 28 | 600 | 30.8 | −1.12px | lh 1.10 · ls −0.040em |
| 24 | 480 | 32 | −0.48px | lh 1.33 · ls −0.020em |
| 18 | 400 | 24–28 | normal | lh 1.33–1.56 |
| 16 | 400 | 22–24 | normal | |
| 15 | 400 | 24 | normal | nav |
| 14 | 400/480 | 21 | normal | |

**Rules extracted:** every display size uses **lh exactly 1.10** and **ls exactly −0.04em**; body switches to lh 1.33–1.56 and ls normal. Uses variable weight **480** (not 500) — only possible with a variable font, and a tell of real type craft.

### Colour — full OKLCH semantic system, 206 custom properties
Background elevation is expressed as **lightness steps, not shadows**:
`--bg-depth 95.49%` → `--bg-base 96.99%` → `--bg-primary 98.51%` → `--bg-secondary/tertiary/quaternary 99.99%` (all hue 107 — a *warm* grey, never neutral #F5F5F5).

Foreground ramp, 4 steps: `--fg-primary 10%` → `--fg-secondary 30%` → `--fg-tertiary 50%` → `--fg-quaternary 69%`.

Six semantic families, each generated by the same formula:
| role | solid `--bg-*` | text `--fg-*` | border |
|---|---|---|---|
| accent | oklch(52.43% .2396 264.41) blue | 43.93% | 61.32% @ .4 |
| destructive | 58.53% .2203 26.56 red | 49.84% | 67.30% @ .4 |
| special | 58.99% .2523 294.88 violet | 50.33% | 67.75% @ .4 |
| positive | 54.42% .1689 138.23 green | 45.82% | 63.46% @ .4 |
| attention | 58.01% .1819 40.04 orange | 49.33% | 66.84% @ .4 |
| highlight | 59.06% .2244 359.16 magenta | 50.26% | 67.92% @ .4 |

**The formula:** text = solid − ~8.5% L. Border = solid + ~8.9% L at α .4. Translucent fill = solid at α **.16**. Interaction glow = solid at α **.08** hover / **.16** pressed; neutral glow = black **.04** hover / **.08** pressed. One alpha ladder — .04 / .08 / .16 — reused everywhere.

### Shadow system (this is the "expensive" tell)
`--shadow-surface-xxs…xl` is **cumulative**: each larger step ADDS one layer, offsets doubling and spread halving —
`1px/1px −0` → `3px/3px −1.5` → `6px/6px −3` → `12px/12px −6` → `24px/24px −12`,
every layer at a constant **`#0000000a` (4% black)**, plus a hairline ring `0 0 0 1px rgba(119,119,113,.16)`.
→ Many near-invisible 4% layers, never one heavy shadow.

Buttons are physical, not flat: `--shadow-button-*` = inset top `1px #fff` (light edge) + inset bottom `1px #fffc` (dark edge) + a coloured inset ring in a darker shade of the accent (`#11318c` under blue) + two outer shadows. Plus `--gradient-button-neutral: linear-gradient(to bottom, transparent, #0000000a)`.
Inputs invert it: `--shadow-input-base` = inset top shadows + a `1px #fff` bottom outer line → inputs read *pressed in*, buttons read *raised*.

### Motion
Durations in use: 0.1 / 0.15 / 0.2 / 0.25 / 0.3 / 0.35 / 0.5 s.
Easings: `cubic-bezier(.4,0,.2,1)` micro · `cubic-bezier(0,0,.2,1)` entrances · `cubic-bezier(.16,1,.3,1)` @0.25s colour · `cubic-bezier(.33,1,.68,1)` @0.35s · `cubic-bezier(.215,.61,.355,1)` for the background system.

**Hero background is a `<canvas>` 2400×2420**, not a CSS gradient, driven by three animations:
`background-enter` 1.6s `cubic-bezier(.215,.61,.355,1)` (one-shot) · `background-ambient` **40s `steps(100, jump-none)`** (slow ambient drift, 100 discrete states) · `background-parallax` linear, scroll-tied.

### Restraint
Radii: 4 / 6 / 8 / 10 / 12 / 16 / 24 / 28 / 32 + pill. Prompt box = **28px**.
**`backdrop-filter` appears on exactly ONE element on the whole page** — `blur(4px)` on the prompt input. Glass used once, on the single most important element.

**Pro $25/mo** — 100 credits, rollovers, top-ups, unlimited lovable.app domains, **custom domains**, roles & permissions, per-member credit limits, remove Lovable badge, email support.

## 2. Bolt.new (StackBlitz)

**Typeface:** `Inter` + **`Inter Display`** for headings (optical-size cut).
**Page bg:** `#171719` (dark). Blue radial glow, CSS not canvas. `--grid-dot-opacity: 32%` dot grid.

### Type
48/48 (**lh 1.00**) w700 ls −1.2px (−0.025em) Inter Display · 36/40 w700 ls −0.9px · 30/36 w600 · 24/32 w600 Display · 20/28 w600 Display · 18/28 w400–600 · 16/24 · 14/20.

### Colour — `--bolt-ds-*`, RGB triplets, 167 vars
Brand `43 166 255` = **#2BA6FF**, hover `20 136 252`.
Semantics are **stock Tailwind**: success `34 197 94` (green-500), warning `247 144 9`, danger `239 68 68` (red-500).
Subtle-fill ladder per semantic: `BgSubtle` **α 5%** (`0d`) → hover **10%** (`1a`) → border **20%** (`33`).
Text ramp 3 steps: `12 12 15` → `82 82 88` → `115 115 123`.
**Icons get their own ramp** with a lighter tertiary (`164 163 172`) — icons carry less contrast burden than text.
Also `--agent-color` / `--model-color` custom props → per-agent/model theming.

### Prompt box
640px wide · radius **24** · bg `#1E1E21` · border `1px #2C2C30` · shadow `0 0 40px −12px rgba(0,0,0,.35)`.
Backdrop `blur(10px) saturate(1.2)` — the iOS glass recipe (blur **with** saturation).

### Motion
Sparse: 0.15 / 0.2 / 0.3s, almost all `cubic-bezier(.4,0,.2,1)`. **Zero keyframe animations on the landing page.** Bolt is markedly less animated than Lovable.

### Chat-bubble radius system
Asymmetric sets: `24px 12px 12px` / `12px 24px 12px 12px` / `12px 12px 12px 24px` / `12px 12px 24px` — one corner 24, the rest 12, rotated by sender & position in the group.

### Landing UX
Under the prompt: four **output-type chips — Website / Slides (New) / App / Prototype** — the user picks the artifact type *before* generating. Plus "or import from **Figma** / **GitHub**". Mode selector "Plan" inside the box; CTA "Build now ▶".

### Verified pricing (13.08.2026) — sells **tokens**, not credits
Free $0 — 300K tokens/day, 1M/mo, Bolt branding, 10MB upload, hosting, **up to 333k web requests**, unlimited databases.
**Pro $25/mo** — no daily limit, from 10M tokens/mo, no branding, private sharing, 100MB upload, **1M web requests**, rollover, **custom domain support**, SEO boosting, expanded DB, choice of DB provider, AI image editing.
Teams $30/mo/member — centralized billing, admin controls, private npm, **design-system knowledge with per-package prompts**.
Yearly saves up to 28%.
→ **Custom domain gated at $25/mo. Meters hosting traffic (web requests) — nobody else does.**

## 3. v0 — v0.app (Vercel)

**Typeface:** `GeistSans` (Vercel's own).
**Page bg:** `oklch(0 0 0)` — **pure black**.

### Type — an optical tracking ramp
48/56 w600 ls −2.88px = **−0.060em**
32/40 w600 ls −1.28px = −0.040em
24/32 w600 ls −0.96px = −0.040em
20/26 w600 ls −0.40px = −0.020em
18/28, 16/24, 14/20, 13/19.5 — all ls normal.
→ Tracking tightens as size grows: −0.02 → −0.04 → −0.06em. Body never tracked.

### Motion — one signature curve
**`cubic-bezier(0.31, 0.1, 0.08, 0.96)`** at 0.15 / 0.2 / 0.3 / 0.35 / 0.5s — Vercel's house ease, used for nearly everything.
Plus a spring `cubic-bezier(.34,1.56,.64,1)` @0.6s on a couple of transforms (deliberate overshoot).
Only keyframe animation on the page: a 24s linear logo marquee.

### Restraint
Prompt box: 690px · radius **12** · bg `oklch(.182 0 0)` ≈ #212121 · border `1px oklch(.39 0 0)`.
Radii: 4 / 6 / 8 / 12 / 16 / 35 + pill. **Zero `backdrop-filter`. Zero gradients.** Uses Vercel's `--ds-*` Geist tokens.

### Landing UX
Model selector **inside** the prompt box ("v0 Max ⌄"). Suggestion chips (Contact Form / Image Editor / Mini Game / Finance Calculator) with a **↻ reroll button**. Community template gallery on the logged-out homepage, each card with author avatar + view count + like count (6.4K · 714).

## 4. Base44 (Wix)

**Typefaces:** body `WixMadeforText` (Wix's corporate face — the acquisition is now visible in the brand), display **`Dazzed`** (licensed geometric grotesk). One "$" glyph falls back to `Geist`.
**Page bg:** `#F9F8F6` (warm off-white) + faint dot grid.

### Type — fluid, editorial, very tight
92.77/97.41 w600 ls −3.71px (−0.040em, lh 1.05)
92.03/**81.63** w600 ls −3.68px → **lh 0.887 — sub-1.0 leading on multi-line display**
56.43/59.25 ls −2.26px (−0.040em)
35.63/38.48 ls −0.74px (−0.021em)
→ Sizes are viewport-fluid (non-integer px). Tracking −0.04em on display, same as Lovable/v0.

### Colour
`--brand: 28 96% 61%` ≈ **#FA8231 orange**, hover `28 82% 55%`. Otherwise **stock shadcn** HSL vars still in `:root` (`--background 240 10% 3.9%` etc.) — built on shadcn, brand layered on top. `--radius: .75rem`. Chart palette `--chart-1…5` shipped (they have analytics).

### Shape
Radii only **2 / 6 / 8 / 10 + pill** — much squarer than the others. Prompt box radius **8px**, white, no shadow, 549px.
App shell tokens: `--header-bar-h: 44px`, `--header-margin: 8px`, `--header-offset: 52px`.

### Motion
0.15 / 0.16 / 0.2 / 0.3s, mostly `ease` and `cubic-bezier(.4,0,.2,1)`. One notable: `clip-path 0.36s cubic-bezier(.22,1,.36,1)` (expo-out reveal).

### Landing UX
Output-type switcher rendered as an **editorial text row**, active item in brackets: `[Apps] • Websites • Games • Tools` — not chips. Orange square send button (↗) inside the prompt box, "Build ⌄" mode selector, mic.

## 5. GoDaddy Airo AI Builder

**Typefaces:** `gdsherpa` / `gdsherpaVF4` (GoDaddy's proprietary variable face; weights 450 / 695 / 700 / 850 in use) + **`Instrument Serif` italic** as the display accent ("…in *minutes*.", "…*friendly*."). The accent word is `color: rgba(0,0,0,0)` → gradient text via background-clip (purple).

### Type — the craft gap, in one number
Fluid sizes 83.23 / 65.76 / 51.96 / 46.18 / 41.05 / 32.44 / 28.83…
**line-height is a constant 1.25 on every heading. letter-spacing is `normal` everywhere.**
→ Everyone else tracks display type −0.02…−0.06em and leads it at 1.0–1.1. Loose, evenly-led display type is the single most legible "corporate/dated" tell here.

### System hygiene
**571 CSS custom properties with hashed names** (`--ux-1s0t9v0`, `--ux-97h3vl`) — machine-generated, not semantic. Compare Lovable's 206 human-readable OKLCH tokens.
Radii in use: 4, 6, 8, 12, **21.6**, 26, 32, 46, 50, 50%, 9999 — no radius scale.

### Motion
Scroll reveals at 0.3–0.6s on `cubic-bezier(.16,1,.3,1)` (expo-out) and `cubic-bezier(.1,.25,.3,1)`. Competent, but applied over a dated type system.

### The strategic twin — verbatim funnel copy
- Hero: **"Describe your idea. We do the rest in minutes."** (near-identical to Remixer's "Describe it. Remixer builds it.")
- **"Start for free with 50 AI credits a month. No credit card required."**
- Suggestion chips: "Redesign with a fresh look →" · "Build an online store →" · "Create a business directory →"
- Audience tabs: Web Apps / Websites / Online Stores / Dashboards / Portfolios
- Three-step frame: **"1. Describe what you want. 2. Refine your design. 3. Point, click, launch."**
- Section headings: "Skip the blank canvas" · "Easy editing as your app evolves" · **"Publish fast, with the backend built in"** · "Affordable plans, astounding results"
- "One-click deploy on GoDaddy hosting, SSL, forms, and analytics is baked in… **export your code anytime**"
- "rides on GoDaddy's proven stack—**custom domains, built-in hosting**, and enterprise-level security"
- Positioning line: **"Developer-ready. Newbie-friendly."**
- "Type your idea in **any language**" · 150+ countries, multi-language
- Trustpilot block: "Excellent · 4.4 / 5 based on 139,319 reviews"
- Tiers: **Free / Starter / Professional / Ultimate**, Annual↔Monthly toggle (€8.49 visible on annual).

### The legacy-host trap, visible on screen
Two stacked navigations: GoDaddy's global commerce nav (Domains ▸ 7 items, Websites ▸ 5, Email, Hosting ▸ 4, Marketing ▸ 7, SSL, Pricing, Deals, Help, Sign In, cart badge) **above** the product's own sub-nav (Airo AI Builder · Overview · My Projects · Start for Free). The product never gets the top of the screen.
