> **Назначение:** одно слово = одно значение. Здесь глагольная система, правила

## 1. Глагольная система (правило аудита, обязательно)

| Глагол | Значит ровно это | Где применяется |
|---|---|---|
| **Add** | **купить** новый домен | поиск → выдача → чек-аут |
| **Connect** | подключить домен, который уже **твой** | свои домены в аккаунте DreamHost + внешние |
| **Publish** | опубликовать впервые | панель Publish, первый выход в live |
| **Update** | **переопубликовать** уже живой сайт | панель Publish, когда есть неопубликованные правки |

Один глагол = одно действие. «Connect · free» не писать — если это твой домен, кнопка
просто **Connect**.

⚠️ **Открытое расхождение: `Add` против `Buy`.** Словарь аудита говорит «Add = купить»,
а макет доменного дашборда (Figma 27085:106382) рисует на новых доменах **Buy**.
В прототипе реализовано **по макету**, вопрос поднят дизайнеру и не закрыт.
Решать один раз и глобально: два глагола на одно действие — худший из вариантов.

## 2. Де-жаргон: чего не говорим в основных путях

Аудитория — полный новичок («housewife test»). В основных путях **нет** этих слов:

`DNS` · `nameserver` · `A record` · `CNAME` · `301` · `SSL certificate provisioning` ·
`publish to production` · `propagation`

Вместо них:

| Вместо | Говорим |
|---|---|
| смена nameservers | **«Point domain to us (easiest)»** |
| редирект | **«Redirects to {domain}»** |
| DNS propagation / provisioning | **«Connecting your domain»** + «Usually a few minutes — keep editing, it goes live on its own» |
| SSL certificate | **«secure padlock»** |
| production | **«Public website»** (а staging — **«Private preview link»**) |

Технические слова допустимы только на «продвинутом» экране для тех, кто сам его открыл.

## 3. Канонический чеклист успеха

Один и тот же порядок на КАЖДОМ экране успеха, без вариаций:

> **Domain settings updated · Connected to your site · Security (SSL) on**

## 4. Правила копирайта

- **Цену показываем до корзины.** Renewal-цену не прячем — иначе dark pattern.
  На карточках месячная рамка («from $9.99/mo»), полный годовой итог — в чек-ауте.
- **Каждое обещание говорим один раз.** Карточка — максимум ~2 короткие строки.
- Не обещать «мгновенно защищено»: SSL приезжает 10–30 минут (`product-facts.md` §5).
- Не обещать письмо/пуш о выходе в live — это не подтверждено (`product-facts.md` §9).
- Язык продукта — **английский** (рынок США). В прототипе i18n: EN по умолчанию, UK вторым.
  Проза документов для дизайнера — русский.

## 5. Продуктовые термины

| Термин | Что это |
|---|---|
| **Remixer** | AI-билдер сайтов DreamHost: «builds your site from a conversation» |
| **Remixer Build** | платный план, $9.99/мес (см. `product-facts.md` §1) |
| **Credits** | внутренняя валюта AI-действий: 1 000/мес, +1 000 бонус в первый месяц |
| **Private preview link** | бесплатный `*.remixer.site`, всегда доступен, скрыт от Google |
| **Public website** | кастомный домен — момент удержания, требует платного плана |
| **Launchpad** | выбранное направление панели Publish (⑥-A): один герой + демотированная строка превью |
| **Zero-record connect** | подключение домена, который уже лежит в аккаунте DreamHost: ни одной DNS-записи пользователю не показано. Наш главный overtake-ход |
| **Domain Connect** | открытый стандарт, которым регистратор сам пишет записи по запросу сервиса. **DreamHost его не поддерживает ни в какой роли** |
| **Entri** | покупной сервис, делающий то же самое one-click (его используют Replit и Lovable) |
| **EPP / auth code** | код авторизации трансфера, выдаёт текущий регистратор |
| **ICANN 60-day lock** | запрет трансфера 60 дней — после регистрации, после трансфера и после ЛЮБОГО изменения данных владельца, включая приватность |
| **Nameservers** | `ns1/ns2/ns3.dreamhost.com`; обновление 4–72 ч |
| **WHOIS privacy** | у DreamHost бесплатно навсегда |
| **Register / Renew / Transfer** | три колонки официальной таблицы цен; в UI всегда носим первые две |
| **Premium domain** | домен вторичного рынка. DreamHost их **не продаёт** → состояния «Make an offer» нет |
| **Liftoff** | текущий (не-Remixer) билдер DreamHost; поиска доменов внутри билдера у него нет |
| **Business Name Generator** | существующий бесплатный AI-нейминг DreamHost, живёт отдельно от поиска доменов |
| **SmartEdge** | глобальный CDN DreamHost, входит в план |

## 6. Внутренние термины прототипа

| Термин | Что это | Где |
|---|---|---|
| **World** | единственный объект состояния, из которого рендерятся все экраны | `prototype/src/state/world.ts` |
| **Оси состояния** | `account` (anonymous/trial/trial-expired/paid) × `inventory` (что за домены у юзера) × `domain` (что делает домен проекта) × `project` × `chat` | `world.ts` |
| **Inventory** | `none` · `dh-free` · `dh-in-use` · `dh-external-ns` · `external-dc` · `external-manual` | `world.ts` |
| **Domain state** | `staging` · `searching` · `checkout` · `connecting` · `verifying` · `live` · `unreachable` · `multiple` | `world.ts` |
| **Flow** | декларативный сценарий, проигрываемый от начала до конца для демо (шаги с реальным выбором ставят `awaitUser`) | `state/flows.ts`, `devtools/FlowPlayer.tsx` |
| **Scenario** | заготовленное мировое состояние (консоль сценариев) | `state/scenarios.ts`, `devtools/ScenarioPanel.tsx` |
| **Remixer glow** | фирменное свечение по кромке превью во время процессов | `ui/SiriGlow.tsx`, `handoff/siri-glow-spec.md` |
| **Send flash** | «налить и слить» вокруг композера при отправке | `index.css`, секция «The send flash» |
| **Governor** (губернатор качества) | измеряет fps ВО ВРЕМЯ свечения и режет слои на слабых машинах | `ui/SiriGlow.tsx` |
| **Spacer** (спейсер) | распорка в конце треда, которая позволяет уводить отправленное сообщение наверх вьюпорта | `modules/chat/ChatPanel.tsx` |
| **ScrollArea** | единственный разрешённый способ сделать поверхность скроллящейся; тона `light` / `dark` / `auto` | `ui/ScrollArea.tsx` |
| **site-stage** | контейнер превью; сайт внутри отвечает на container queries, а не на ширину окна | `index.css` |
| **Compact** | сжатое состояние шапки доменного поиска (герой оседает в выдачу) | `modules/domains/DomainsSurface.tsx` |
