## 4. Регистратор: чего DreamHost не умеет

| Факт | Статус · дата |
|---|---|
| **Премиум-домены не продаются**, брокериджа нет: «DreamHost does not currently sell premium domain registrations… you need to register it directly with Enom or another registrar» → состояний «Make an offer» / aftermarket в дизайне быть не должно | verified · 06.08.2026 |
| **Domain Connect не поддерживается ни в какой роли**: нет ни одного упоминания на help.dreamhost.com, DreamHost отсутствует в списке провайдеров domainconnect.org | verified · 06.08.2026 |
| One-click подключение внешнего домена возможно только через покупку **Entri** (~$249/мес за 600 доменов/год, $749/мес с custom-domain SSL — цена unverified). Так сделали Replit и Lovable | verified (механизм) / unverified (цена) · 13.08.2026 |
| ⚠️ Не делать DreamHost **провайдером** Domain Connect — это ускоритель оттока | правило · `CLAUDE.md` |
| Бесплатный домен на 1-й год действует **только** для годовых Web Hosting / DreamPress: «This free credit is not available under any other hosting plan» → билдер-план по документации не квалифицируется; хук не использовать в основном флоу | verified · 06.08.2026 |
| Регистраторский бэкенд — вероятно Enom (по IPS-тегу .co.uk и по формулировке premium-FAQ) | likely · 06.08.2026 |
| Публичный поиск доменов работает через `marketing-api-aws.dreamhost.io/ajax.cgi?cmd=domreg-availability`, за invisible reCAPTCHA; при низком score — HTTP 500 и карточка ошибки «Something went wrong! Please try your search again, or contact support for assistance.» | verified · 06.08.2026 |
| У DreamHost уже есть AI-нейминг: бесплатный **Business Name Generator** (с сент. 2023) — теги + индустрия → имена → проверка домена в реальном времени → регистрация на месте. Это единственная AI-наименовательная фича, и она ЖИВЁТ ОТДЕЛЬНО от поиска доменов | verified · 06.08.2026 |

| Порядок обязателен: сначала перевести nameservers, потом начинать трансфер — «changes to nameservers cannot be made while a domain transfer is in progress» | verified · 06.08.2026 |

## 8. Открытые расхождения между источниками

Зафиксированы, а не «исправлены молча». У каждого сказано, **какой источник правит
сегодня** и **какое решение и от кого нужно**, чтобы расхождение закрылось.

1. **`.io` — $39.99 (хендофф, июнь 2026) против $34.99 (официальная таблица, 06.08.2026).**
   Правит таблица (так же прямо сказано в `CLAUDE.md`).
   → **Нужно:** дизайнеру — обновить цифру в макетах покупки; закрывается без чьего-либо
   согласования, это просто устаревшее число.
2. **`.online` — $0.99 (хендофф) против $1.99 / renew $29.95 (таблица).** Правит таблица.
   → **Нужно:** дизайнеру — обновить цифру в макетах.
3. **`.ai` — «$179.98 (2-yr min)» (хендофф) против «$89.99/год, минимум 2 года» (таблица).**
   Одно и то же число, поданное по-разному; правит подача таблицы.
   → **Нужно:** дизайнеру — решить формулировку в UI (мы показываем «$89.99/yr · минимум
   2 года», а не «$179.98»), и держать её одинаковой на всех экранах.
4. **Domain Connect: нарисован путь, которого у продукта нет.** Хендофф (сценарий ③)
   описывает «Domain Connect one-click для ~50 регистраторов»; verified-факт — DreamHost
   **не поддерживает Domain Connect ни в какой роли**, значит нарисованный one-click
   сегодня невыполним. Правят `CLAUDE.md` и ресёрч; хендофф в этой части устарел, но не
   переписан — на него ссылается страница Figma.
   → **Нужно:** решение продукта/бизнеса — покупать Entri (~$249/мес, unverified) или нет.
   Пока не куплено, дизайнеру придётся перерисовать ③ на ручной путь с сильным
   hand-holding. Это блокирует весь сценарий «внешний домен».
5. **Цена продления `$11.86` в макетах чек-аута** (борды 27058 / 27254 / 27275) не
   встречается ни в одной строке проверенной таблицы — плейсхолдер. В прототипе цены
   берутся из `TLD_PRICES`.
   → **Нужно:** дизайнеру — заменить плейсхолдер на цену из таблицы, чтобы борд нельзя
   было прочитать как утверждение о цене.
6. **Фон билдера `#18181B` (verified-факт продукта) против `#09090B` (редизайн 2026,
   Figma 28016:42812).** Оба верны в своих рамках; прототип рисует `#09090B`, потому что
   рисует новый макет.
   → **Нужно:** дизайнеру — подтвердить, что `#09090B` и есть целевой фон (тогда
   `#18181B` остаётся только описанием «как в продукте сегодня»), иначе развести два
   значения по названиям, чтобы никто не подставлял одно вместо другого.
7. **Глагол на новом домене: «Add» (словарь аудита) против «Buy» (макет доменного
   дашборда 27085:106382).** Реализовано по макету.
   → **Нужно:** решение дизайнера — один глагол на действие, глобально по всем экранам.
   Два глагола на одно действие — худший из трёх возможных исходов. См. `glossary.md` §1.
8. **Кредиты за публикацию** — факт продукта (verified: кредиты тратятся на публикацию)
   против вывода аудита №1 («публикация должна стоить 0 кредитов»). Прототип уже сделан
   по выводу аудита: публикация кредитов не списывает.
   → **Нужно:** решение продукта — снять плату за публикацию или сознательно оставить.
   Пока не решено, прототип и продукт расходятся в самом заметном месте, и любая
   сравнительная таблица конкурента бьёт именно здесь.

**Закрыто 25.08.2026** (для истории, чтобы не открывали заново): в `CLAUDE.md` были две
устаревшие цифры — задержка прокрутки треда «320 мс» (в коде 620) и рамка стекла «15 %»
(в коде `#ffffff1f` = 12 %). Обе приведены к коду.
