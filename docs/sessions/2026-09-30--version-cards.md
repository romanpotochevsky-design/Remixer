## Заказ

Дизайнер с бордом `31422:42642` и скриншотом с аннотациями: карточка каждого изменения сайта в чате — revert, глаз
(просмотр старой версии в превью, как у Lovable), шеврон (детали); текущая — зелёная точка и только шеврон;
бесплатные правки Visual Editor — «T в рамке» и без текста AI; «больше двух бесплатных изменений подряд
схлопываются в один стек, как уведомления iPhone в шторке, с кружком-счётчиком»; полная имитация изменений через чат и
через инструменты текста/фото. Потом: «я пошёл спать, выполняй полностью… крутые apple liquid glass анимации… всё
продумаешь грамотно и профессионально».

## Что сделано

1. **Ресёрч** — Lovable (сохранённые страницы из GitHub с датами, доки: Versioning 2.0, restore = новая версия, «Undo
   latest edit», жалобы), Bolt (eye + стрелка возврата — ровно иконки борда, «Restore version», сообщение об успехе),
   v0 / Replit / Base44 / Airo. iOS-стек — по поведению шторки (тап раскрывает, «Show less», новая сверху).
2. **Борд прочитан до пикселя** через Plugin API и `get_variable_defs` в тёмной теме; глифы сняты `exportAsync`
   (`modules/versions/icons.tsx`); спека — `prototype/scratchpad/version-cards/board-spec.md`.
3. **Модель**: оси сайта `world.versions` + `world.siteAi`, `ui.versionPreview`; откат — новая версия сверху;
   текущая — последняя приземлившаяся; снимки — два маленьких слоя.
4. **Чат меняет демо-сайт по-настоящему**: каталог `changes.ts` (nav, testimonials, pricing, FAQ, order form, photo
   strip, bigger cards, палитры, заголовок, mobile, generic, страницы Autopilot) и блоки `site-ai.tsx`; палитра —
   переменные `--sa/--sd/--sp` у сайта.
5. **Карточка** (`VersionCard.tsx`) по борду; «в работе» → оседает; детали — `Reveal`; подтверждение отката;
   строка Remixer после отката.
6. **Стек** (`VersionRun`): FLIP по трансформам, высота из карточек на каждом кадре, веер, «Show less», подъём
   подглядывающих при наведении.
7. **Просмотр**: снимок на канвасе с «проседанием», панель внизу канваса (`PreviewBar.tsx`), синее кольцо, Esc.
8. **Visual Editor**: Save пишет бесплатную версию (правило «без строки в треде» заменено).
9. **Консоль**: пресет «Versions — the board’s thread» (`demo.ts` гоняет функции живого флоу).
10. **Проверка**: пробники `probe.mjs` (17), `film.mjs` (10, покадровые трассы), `preset.mjs`; блок **R** сюиты;
    два независимых ревью (код и UX) — найдено и исправлено: Save посреди работы Remixer подвешивал чат; устаревший
    гейт «грязного» редактора; «проседание» застревало на полпути при быстром Esc; «Keep working» Autopilot рождал
    фальшивую версию; перезагрузка после принятой страницы строила FAQ; смена сайта посреди работы; повторный вход
    карточки при вхождении в стек; ключевые слова («preview» ловило отзывы, «navy» — навигацию); украинские
    числительные. UX: формулировки отката против главной ошибки новичка, строка после отката, копирайт деталей.
