## Как стартовать новую сессию (порядок обязателен)

1. `git fetch origin --prune && git checkout -B claude/remixer-connect-domain-flow-4fpgqc
   origin/claude/remixer-connect-domain-flow-4fpgqc` — контейнеру могут назначить другую ветку,
   без этой работы. Пушить туда же.
2. Прочитать `CLAUDE.md` целиком, затем этот файл и раунды 40–43 журнала.
3. `cd prototype && npm install && pip install fonttools brotli` (без `pyftsubset` артефакт не влезет
   в лимит публикации).
4. Превью: `(setsid nohup npx vite preview --port 4173 --strictPort > /tmp/preview.log 2>&1 < /dev/null &)`
   после `npm run build`; сюита:
   `CHROME=/opt/pw-browsers/chromium-1194/chrome-linux/chrome npm run check:brief` (в фоне, ~7 мин).
5. Перед публикацией — `Artifact action: read` живой ссылки (правило «читать то, что лежит по
   ссылке»), затем `npm run artifact` и публикация с `url`; если файл больше `CEILING` и публикуется —
   поднять `CEILING` и дописать размер в список `CLAUDE.md`.
6. Слоу-мо и трассы — по образцу `prototype/scratchpad/attach-menu/` (`trace.mjs`, `film.mjs`);
   покадровые PNG в репозиторий не кладутся, листы `sheet-*.jpg` и стилы — кладутся.
