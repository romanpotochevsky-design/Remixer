## Открытые вопросы дизайнеру (собраны по раундам, ждут его слова)

1. **Меню вложений:** ховер 8 % стоит на самой пилюле домена, хотя нажимается только её ✕ — оставить
   или ховер только на ✕ (одна строка CSS)? Блик по ободу чипа при появлении — тот же, что у карточек
   треда; если на маленькой пилюле ярок — одно число. Уровень со списком доменов и ширина 280 — наши,
   борд рисует только два ряда. `Attach File` показывает имя файла чипом, загрузки нет.
2. **В билдере домен из intake нигде не показан** (`world.intakeDomain` доезжает до проекта, но ни
   шапка, ни панель Publish его не называют) — весь смысл заказа 21.09 в том, чтобы было видно.
3. **Окно Cloud:** шапка колонок на 4 px левее данных (слоп мока, оставлено как нарисовано); плита
   выбранной комнаты — наша экстраполяция борда; Selected берёт только Cloud, у Style / Extension /
   Analytics окон нет.
4. **Панель Publish:** на `ready + icann` чип топбара говорит «Setting up your domain», строка окна
   доменов — «Connecting», хотя подключение объявлено законченным; `Unlink` без подтверждения (борд
   рисует одну кнопку); нативные `title` контролов не переведены в стеклянный тултип.
5. **Бриф и план:** плейсхолдер поля `gray-400` против `#ffffff7a` борда; сводка брифа — пять рядов
   при четырёх на борде 29848:28823; карточка генерации разошлась по анатомии со сводкой; в
   упрощённом плане структура не редактируется; в полном варианте строки — поля, а не документ.
6. **Домашняя:** девять контролов на нелегальных 36 px (правило 32/40/48); что делают `Use Template`
   и `+ Add Prompt` — не решено.
7. **Домены:** нет состояния «домен занят»; шит покупки озаглавлен `Connect domain` при кнопке

## Как стартовать новую сессию (порядок обязателен)

1. `git fetch origin --prune && git checkout -B claude/remixer-connect-domain-flow-4fpgqc
   origin/claude/remixer-connect-domain-flow-4fpgqc` — контейнеру могут назначить другую ветку,
   без этой работы. Пушить туда же.
2. Прочитать `CLAUDE.md` целиком, затем этот файл и раунды 40–43 журнала.
3. `cd prototype && npm install && pip install fonttools brotli` (без `pyftsubset` артефакт не влезет
   в лимит публикации).
4. Превью: `(setsid nohup npx vite preview --port 4173 --strictPort > /tmp/preview.log 2>&1 < /dev/null &)`
   после `npm run build`; сюита:
   `CHROME=/opt/pw-browsers/chromium-1194/chrome-linux/chrome npm run check:brief` (в фоне, ~7 мин).
5. Перед публикацией — `Artifact action: read` живой ссылки (правило «читать то, что лежит по
   ссылке»), затем `npm run artifact` и публикация с `url`; если файл больше `CEILING` и публикуется —
   поднять `CEILING` и дописать размер в список `CLAUDE.md`.
6. Слоу-мо и трассы — по образцу `prototype/scratchpad/attach-menu/` (`trace.mjs`, `film.mjs`);
   покадровые PNG в репозиторий не кладутся, листы `sheet-*.jpg` и стилы — кладутся.
