## Что сделано

- `VersionRun` (`modules/versions/VersionCard.tsx`): на лицевой карточке сложенного стека — слой `.vc-glow` из двух
  пятен, оба обрезаны радиусом карточки 16: растушёванное пятно внутри (280 px, белый 5 % → 2,5 % → 0) и след на ободе
  (кольцо-маска 1 px над пятном 200 px, 22 % → 8 % → 0) — край ловит свет рядом с рукой.
- Позиция указателя пишется прямо в DOM (`--gx/--gy`, `aimGlow`), пятна едут `transform` — без ререндера и без
  перерисовки градиента на каждом движении. Проявление 240 мс, уход 320 мс — вместе с подъёмом подглядывающих карточек.
- Только мышь; у раскрытого стека свечения нет.
