   нас в режиме правятся и текст, и фото».**

  единой фотографии (эмодзи на градиентах), тексты в JSX-литералах, карточки с key по имени;
  превью смонтировано в четырёх местах (канвас, SiteMini полки и дока, клон PickFlight).
  Конкуренты: категория разошлась на два лагеря — Lovable/v0/Bolt в 2026 берут кредиты за
  визуальные правки при применении (likely, сниппеты), хостеры и платформы (GoDaddy, Base44,

  представил Visual Editor рядом с чатом (сниппет).
- **UX-критик черновика** снял: «+1 за Save» делает счётчик нечестным; Esc, стирающий набранное;

  (имя блюда на трёх страницах и в таблице Cloud) против правок «по месту»; фото нечего менять;
  синие рамки — идиома, отклонённая для плана 21.09 («как в гугл док»); нет связи чат ↔ редактор.
  Всё это вошло в план вопросами и решениями.

## Открыто дизайнеру (см. сообщение)

ушли из тулбара против вывода аудита №6 · шеврон у имени страницы · иконка девайса (телефон при

## Критик архитектуры (пришёл после черновика; учтено в плане)

- **Блокер:** `SiteMini` на полке и в доке и клон `PickFlight` монтируют `SitePreview` без id сайта — тот
  читает ТЕКУЩИЙ мир. Со второй живой карточкой правки одного сайта покажутся на миниатюре другого.
  Лечение: `SitePreview` получает срез своего сайта (`site` prop → селектор `siteSliceOf(world, id)`
  = текущий мир, иначе `stash[id]`, иначе `SITE_SLICES[id]`).
- **Байты фото — не в World.** `syncUrl` сериализует весь мир в localStorage на КАЖДОМ `set()`;
  data-URL фото в мире делает каждую запись ~40 мс вместо 0,1 (замер критика, headless Chromium),
  дублируется в стеллаже, а переполнение квоты молча выключает всё сохранение. Фото — под своим
  ключом хранилища (`remixer-prototype/media/…`), в мире только `{ kind: 'upload', id }`; ужимать до
  ~800 px; при отказе квоты — явная ошибка в окне замены.
- **Родной ⌘Z гуляет между хостами** (проба критика: Ctrl+Z в композере откатил текст сайта за спиной
  стора). На коммите переписывать textContent хоста императивно (гасит шаги браузера); пока режим
  открыт — capture-обработчик ⌘Z / ⇧⌘Z вне сфокусированного хоста ведёт в стек сессии.
- **F5 теряет правки всегда:** правка пишет `u≥1` в URL, а URL побеждает целиком. Правило «URL равен
  нашему же снимку → восстановить снимок целиком» (заодно спасает planEdits, stash, cart, sent).
- **Оверлей выделения — ОДИН элемент внутри скролл-контента страницы** (едет со скроллом сам, не
  режется `overflow: hidden` карточек), цели — только листья (`data-edit` не вкладывать),
  `pointerover`, не `pointermove`; кнопки сайта (лого, ссылки футера, «Back to home») — не цели.
- **Ключ хранилища не обязан расти:** дефолт не меняется, лечится полнота восстановленного среза
  (`{...SITE_FRESH, ...restored}`), а не бамп, который сотрёт снимок дизайнера. Решить при реализации.
- Гейт входа — только `generating`/`working`, без `reloading` (иначе после каждого переключения сайта
  2,2 с «Remixer работает»). Блюда — один источник (`data/cloud.ts`), не третья копия.
- Артефакт режет глифы шрифтов до используемых: набранные клиентом `é ü ñ` в опубликованном файле
  упадут на системный шрифт — добавить Latin-1 Supplement в хвост сабсета.
