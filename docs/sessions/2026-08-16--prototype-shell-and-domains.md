## Цель

Перевести прототип на **редизайн 2026** из Figma и собрать доменный модуль по бордам:
дашборд, результаты поиска, чек-аут-шит.

## Что сделано

- **Геометрия шелла по узлу 25819:143144:** чат 432 слева, топбары 52, рейл 56 справа,
  фон кадра `#09090B`.
- **Моушен чата:** отправка по-иМессенджеровски, печать ответа по словам, растушёвки по
  спеке Figma, отправка уводит сообщение наверх вьюпорта (как у Lovable).
- **Резайзер чата** с блумом, который следует за курсором; драг вне React.
- **Композер по Figma** — несколько итераций, пока не выяснилось, что токены надо читать в
  тёмной теме: тёмное поле, стеклянные кружки, контурная кнопка отправки.
- **Флеш отправки** — длинная серия итераций (халo вокруг поля → масштаб и тайминг по записи
  Google AI Mode → комета с сужением → «тише» и «не бить по глазам»); финальную форму
  приняли на следующий день.
- **Remixer glow:** исправлен губернатор качества (мерил не тот момент), свечение отложено
  на 700 мс после отправки и снимается за 220 мс — чтобы у пружины пузыря и печати ответа
  были кадры.
- **Переключатель устройств:** одна кнопка, фиксированная рамка 390×844 — сверено по
  видеозаписи билдера Lovable.
- **Доменная поверхность** пересобрана как дашборд по Figma (оба варианта инвентаря),
  затем добавлены **экран результатов поиска** и **чек-аут-шиты** по трём бордам;
  стена плана перед доменной поверхностью убрана, гейт остался только в шите.
- **Панель Publish** приколота к месту из макета, строка connect раскрывается по ховеру.
- Мелкие, но важные починки: возобновление отправки, прерванной перезагрузкой; залипший
  флаг `working` из старых сборок; правило reduced-motion, ломавшее расчёт прокрутки.
- Решения дня записаны в `CLAUDE.md` (`d38c94d`).

## Что решено

Принято: геометрия редизайна (старую 57/64/522 не откатывать); glow — единственный
индикатор загрузки превью; классическая выдача выше AI-имён; один компонент на шесть
состояний чек-аута; цены только из `TLD_PRICES`. Заменено: стекло на панели Publish →
сплошная `gray-850`; короткая пружина отправки → длинная.
Все строки — в `docs/knowledge/decisions.md`.
