  childless-фреймы с видимыми детьми — та же семья лжи, что эллипсы колец).

  прикреплённое состояние нигде не нарисовано), Build сеет билдер промптом + шаблоном.
- Независимая QA (`qa-report-add-template.md`): fixed point пружины восстановлен из
  15 кадров — центр пилюли с точностью до трети пикселя; контент отстаёт на ~90 мс;
  выход в 2.1× короче. Найден и починен реальный дефект: `aria-modal` при клавиатуре,
  оставшейся целиком снаружи шита (такой же пробел записан за доменным чек-аутом —
  на следующий проход по доменам).

### Fluid-сетка (просьба дизайнера, референс — Dribbble)
Кап 1560 снят: фиксированные 32px поля, шесть `1fr`-колонок тянутся на всю ширину;
минимум колонки `max(200px, «шесть-в-ряд» − 1px)` держит шесть колонок сверху (auto-fill
не может добавить седьмую) и роняет колонки 6→5→4→3 снизу; миниатюра — `aspect-ratio`,
карточка растёт пропорционально целиком. На нарисованных 1656 рендер отличается от
закоммиченного бейзлайна на ноль пикселей.

### Детальный просмотр (борд `28637:42088`)
Клик по карточке открывает детальный просмотр (прикрепление переехало на пилюлю
`Choose a template`). Превью **вырастает из карточки бесшовно**: FLIP-морф с вложенным
counter-scale — контейнер меняет аспект, рисунок остаётся равномерным; fixed point
полёта доказан до 0.001px. Пластина ✕ разматывается влево из никогда не движущегося ✕,
контент шапки приходит со ступенькой (← → имя → пилюля), назад перемеряет слот карточки
и садится точно, Esc шагает назад и лишь потом закрывает. Найден баг класса ⚠️:
`visibility` через motion `transitionEnd` молча теряется на блоке, который анимирует и
`y`, — шесть невидимых чипов оставались Tab-стопами.

### Вход страницы (продакшен-хореография, коммит `07093ac`)
Снята покадрово с записи живого продукта: занавес 250/500 мс → сборка логотипа SVGator
300–1850 мс (ассет maintenance-страницы, извлечён в `LogoRemixerAnimated.tsx` +
`svgator-player.ts`) → топбар/заголовок 850, подзаголовок 1000, композер 1250,
чипы+док 1400 (expo) → знак борда кросс-фейдом на 1900 → апертура точек
(composited `clip-path` из-под логотипа) 2000/2800 + пять колец в порядке радиуса
2.0–2.8 с. По `animationend` всё покидает DOM: осевшая страница **байт-в-байт равна
QA-бейзлайну (0 пикселей)**, 59.5 fps в покое, ноль повисших rAF. Театр один раз за
сессию; возврат из билдера — 300 мс фейд. Reduced motion — мгновенно осевшая страница,
статичный знак, переключение ОС посреди театра поймано (`animationcancel`, не
`animationend`).

Пересобрано по полнокадровым фреймам записи (масштаб съёмки 1.6356 device px/CSS px,
выведен из 958px CSS-интерьера композера): краска — два МНК-блума (магента
`rgb(166,71,227)` слева, синий `rgb(48,85,199)` справа; rms 1.87/255, худшая проба 7.1)
с тёмной долиной как ОТСУТСТВИЕМ блумов, земля `#17161c`, плита `Shadow` и вуаль
удалены; решётка — 16px ромбы ~4.9px, **яркая копия цветового поля сквозь ромбовидную
маску** (не 6 % белого — точки пылают над блумами и гаснут в долине); кольца — радиусы
записи [118.6, 248, 401, 536, 704], 8 % белого. Вход перетаймлен: хлопок цвета ~150 мс
(один кадр видео, не фейд), контент 1.05–1.3 с, и с 1.65 по 4.10 с — **волна**, которой
у v1 не было: кольцевой фронт перегорающих точек от логотипа на замеренных
0.385 CSS px/мс, тёмная кайма у молодых точек, кольца в порядке радиуса ~250 мс позади
фронта (2.21–3.73 с); curtain call на 4.45 с (`animationend` волны). Сеттл против кадра
продакшена — худшая из 14 точек 4/255. Цена: маска волны (registered `--wave-r`)
ре-растеризуется ~2.3 с, ~17 fps на софтверном рендере — сознательное
one-shot-исключение из закона «ноль покадрового paint», слой демонтируется на curtain
call, осевшая страница по-прежнему 61 fps.
