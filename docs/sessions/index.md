  в её записи. У закрытой сессии этот раздел тоже читают первым.
- **`реконструкция`** — восстановлено, а не записано в момент работы.

  коммите `ffba495`; к концу 25.08.2026 на ней 20 своих коммитов (Home page + база
  знаний + «Add template»: пикер, детальный просмотр, вход страницы).

  от `ffba495`, HEAD `94c3de5`. Из них 22 — по состоянию на ночь 26.08 (Home page, база
  знаний, «Add template», пересборка героя по записи), и 14 — день 26.08: стекло с
  градиентными ободами и интерактивом, матовые чипы, бар детального просмотра,
