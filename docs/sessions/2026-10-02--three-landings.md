## Что сделано

- **Полка — три сайта, все живые** (`DEMO_PROJECTS`, `thumb: 'live'`): fit-ration (белый — демо-сайт, не тронут),
  synco.com (чёрный магазин аудио), meridianroast.com (яркая обжарочная). still-studio.com убран из полки и из
  `SITE_SLICES`; консоль — «Their three sites».
- **`modules/preview/landings.tsx`** — два лендинга по «паре верхних секций»: шапка + герой + одна секция + футер.
  · synco: полоса Black Friday (из его собственного транскрипта), шапка со стеклом, герой Gilroy/Outfit 64 на
    чёрном, студийный кадр Orb под фиолетовым светом, ряд спеков, «The lineup» — три карточки с перечёркнутой ценой.
  · meridian: оранжевый блок-герой со стикером «−15% every 2 weeks» (тоже из транскрипта — подписка),
    флэтлей латте; тёмная бегущая строка стран; «This month’s roasts» — три пачки на жёлтом / розовом / голубом
    в «стикерных» карточках с тенью-подложкой.
- **Редактор работает на обоих так же, как на fit-ration:** каждый текст — `T`, каждое фото — `Photo`, ключи
  `synco.*` / `meridian.*` в `content.ts`; правки живут в срезе сайта (`siteEdits`). Проверено: Edit → правка
  заголовка → «1 text change» → Save → заголовок и миниатюра на полке обновились; у фото есть «Replace photo».
  У каждого сайта своя библиотека Website media (его фото).
- **Страницы:** у лендинга одна страница — Home (`sitePages(…, landing)`), переключатель страниц не предлагает
  About, которого нет; чужой роут — свой 404 в стиле сайта.
- **Фото — заглушки** (`scratchpad/landing-photos/make.py`, numpy + Pillow, детерминированно; 8 WebP ≈ 78 КБ):
  студийные рендеры (шар, капсулы, кольцо) и флэтлеи (чашка, пачки, зёрна). Сеть сессии не пускает к фотобанкам,
  а генерация через Figma Weave тратит его кредиты — без его «да» не трогал.
- **Старые снимки мира чинятся при загрузке** (`normalizeShelf` в `world.ts`): снимок хранит `projects` целиком,
  и без этого у дизайнера остались бы рисунки и убранная карточка. Ключ хранилища НЕ поднят — бамп выбросил бы и
  сайты, которые он сгенерировал сам. Проверено подставным снимком v6 с пятью карточками.
- При смене сайта страница монтируется заново (ключ `site + path`) — открытый сайт не наследует прокрутку прошлого.
