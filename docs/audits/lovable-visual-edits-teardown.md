# Lovable — панель инструментов превью (Visual Edits) по экранной записи дизайнера

**Источник:** экранная запись Романа `Screen_Recording_2026-09-29_at_22.11.56.mov` — 22,25 с,
2968×1696, 50 fps, живой билдер Lovable (проект «Figure Haven», магазин фигурок SIXTHVAULT).
**Разобрано:** 30.09.2026, покадрово (1 fps обзор, 10 fps панель, 50 fps на трёх переходах).
**Кадры:** `prototype/scratchpad/lov-visual-edits/` — `f1/` (22 кадра по секунде, 1280 px),
`toolbar-sheet*.jpg` (панель по полсекунды, три листа), `slow-act.jpg` / `slow-txt.jpg` /
`slow-sel.jpg` / `slow-pick.jpg` (50 fps), `zoom-*.jpg` (рамки и подписи крупно). Плотные
кадры 10/50 fps в репозиторий не коммитятся (`.gitignore`), пересоздаются из записи за минуту.
**Статус фактов:** всё ниже — verified по записи (что видно на кадрах). Цены и лимиты
(«100 бесплатных правок текста в день», Select как платная сборка) — likely, из веб-сниппетов
30.09.2026 (`prototype/scratchpad/visual-editor-research/research-web.json`), первоисточники
прокси не отдал — перечитать вживую до цитирования руководству.

## 1. Где стоит панель и из чего состоит

Плавающая тёмная пилюля **по центру нижней кромки превью**, поверх сайта (не в тулбаре).
В покое — четыре инструмента: **Select** (курсор в пунктирных углах) · **Edit text** («T») ·
**Draw** (карандаш) · **Comment** (пузырь). При наведении на пилюлю справа выезжает вторая
группа за вертикальным делителем: **«…»** (ещё) и **«›»** (свернуть) — кадры `f1/0003` против
`f1/0001`. Пилюля почти чёрная (замер по JPEG ≈ rgb(5–11, 4–10, 2–8)), полностью скруглённая,
без видимого стекла; тень мягкая.

**Активный инструмент — синий диск с белым глифом** (их синий ≈ rgb(68,97,199) по JPEG-замеру).
Включение — **фейд заливки за ~120–160 мс** (кадры 3,60 → 3,66 с в `slow-act.jpg`), без
масштаба и без пружины. Инструмент остаётся активным, пока не выбран другой: панель — это
переключатель режимов курсора над превью.

## 2. Select — «выбрать элемент и сказать чату»

- **Ховер:** сплошная синяя рамка 1 px по боксу элемента под курсором + **подпись-тег** на синей
  плашке под нижней кромкой рамки, рядом с курсором по x: `span`, `img`, `div`, `p`
  (`f1/0005`, `f1/0022`, `zoom-0050.jpg`). Слова — имена HTML-тегов, не человеческие.
- **Клик:** рамка остаётся, пилюля **переписывается** в `[● select] 1 selection · [Clear]`
  (`f1/0007`, `f1/0009`); в композере чата появляется чип с тегом (`h1`, `img`) и плейсхолдер
  **«Ask Lovable to modify the selected element…»**. То есть Select — это **область для промпта**:
  правка пойдёт через модель, это платная дорожка (likely). `Clear` снимает выделение и чип.
- Пока есть выделение, остальные инструменты спрятаны: пилюля несёт только статус и `Clear`.

## 3. Edit text — правка текста на месте

- **Ховер:** **пунктирная** синяя рамка 1 px по боксу текстового блока (`f1/0013`,
  `zoom-0130.jpg`) — пунктир отличает «можно печатать» от сплошного «можно выбрать».
- **Клик:** каретка встаёт в текст в точке клика, текст правится прямо на странице
  (`f1/0013`: каретка после «FOR»; `f1/0015`: напечатано «пппап»). В композере тоже появляется
  чип `h1` — инструмент заодно выбирает элемент.
- **После первого изменения** пилюля переписывается в `[● T] 1 text change · [Clear] [Send]`
  (`Send` синий). **Send** применяет правку (бесплатно, likely лимит 100/день), **Clear**
  откатывает набранное. Через ~3 с после `Send` (t ≈ 16–17 с) пилюля возвращается к
  инструментам.
- **Переход панели** (`slow-txt.jpg`, 12,46 → 12,58 с): новая пилюля появляется **сжатой по
  ширине, с наехавшими друг на друга словами, и растягивается до полной ширины за ~100 мс**.
  Содержимое не приезжает тактом позже — оно уже стоит и просто разжимается. Это и есть то,
  что читается дёшево: наш язык (Panel Arrival: контейнер, затем контент на такт позже, уход
  140 мс плоско) здесь выигрывает без усилий.

## 4. Свернуть и вернуть

`›` складывает пилюлю в **язычок `‹` у правой кромки превью** (`f1/0019`, 18,0–18,5 с).
Наведение на язычок разворачивает пилюлю **у правого края**, с иконкой «пристыковать» в конце
(19–21 с, `toolbar-sheet3.jpg`); клик по ней возвращает пилюлю в центр низа (21,5 с).
Нам не нужно: у нас две кнопки, сворачивать нечего.

## 5. Что у Lovable сделано хуже — наши точки обгона

1. **Переходы пилюли — растяжение по ширине со сжатым текстом** (§3). У нас — Panel Arrival.
2. **Подписи-теги `span` / `div` / `p`** — слова разработчика. У нас — человеческие имена
   («Heading», «Photo», «Button») или без подписи вовсе там, где каретка сама всё говорит.
3. **`Send` / `Clear`** — глаголы из чата, а не из редактирования; «Send» для бесплатной правки
   текста звучит как отправка модели.
4. **Шесть контролов** (четыре инструмента + «…» + «›») для новичка. У нас две кнопки.
5. **Фото бесплатно не заменить** — только через чат (likely). У нас замена фото — в том же
   бесплатном режиме, что и текст.
6. **Select стоит среди «бесплатных» инструментов, но ведёт в платную дорожку** без предупреждения.
   У нас эта дорожка — отдельная кнопка с иконкой AI (искра), чтобы платное не маскировалось
   под бесплатное.

## 6. Что у Lovable сделано хорошо — берём логику 1:1

- Панель **над превью, у нижней кромки**, а не в тулбаре: инструмент стоит там, где работа.
- **Активный инструмент = синий диск** — состояние видно с любого расстояния.
- **Два вида рамки:** сплошная «выбрать» / пунктирная «печатать».
- **Пилюля переписывается в статус** («1 text change»), пока идёт работа, и **возвращается**
  к инструментам, когда работа принята.
- **Каретка ставится одним кликом** прямо в текст, без промежуточного поля.
