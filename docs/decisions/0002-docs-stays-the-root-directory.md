# 0002. `docs/` остаётся корневой папкой базы знаний

- **Статус:** Принято
- **Дата:** 20.08.2026
- **Контекст-коммиты:** `b940f60`

## Контекст

При перестройке базы знаний (ADR-0001) обсуждалось и переименование корня. Аргумент за
переименование: в `docs/` лежит не документация к коду, а **память проекта** — аудиты,
ресёрчи, решения, факты. Слово `docs` для программиста означает «документация к
библиотеке», и это сбивает: кто-то может решить, что это описание API прототипа.
Кандидаты — `knowledge/`, `kb/`, `wiki/`, `memory/`.

## Решение

**Корень остаётся `docs/`.** Переименования нет.

## Последствия

- Ни одна существующая ссылка не ломается. На пути внутри `docs/` ссылаются: `CLAUDE.md`
  (читается в начале каждой сессии), `README.md`, код прототипа
  (`prototype/src/state/world.ts`), сами документы друг на друга, тела коммитов и
  **опубликованные артефакты**, которых мы уже не можем отредактировать задним числом.
  Перестройка 20.08 и без того тронула все пути; переименование корня удвоило бы объём
  ремонта ссылок при нулевой прибавке знания.
- `docs/` — конвенция, куда и человек, и агент смотрят первым делом. Своё имя пришлось бы
  объяснять в каждом задании субагенту.
- Плата: имя папки не говорит, что внутри память проекта, а не документация к коду. Эту
  работу делает **первый абзац `docs/INDEX.md`**, который прямо объясняет, что это за
  папка. Одно предложение вместо ремонта всех ссылок.

## Отклонённые альтернативы

- **`knowledge/`** — точнее по смыслу, но требует ремонта всех ссылок и объяснения в каждом
  задании; выигрыш чисто косметический.
- **`kb/`** — короче, но аббревиатура, которую надо расшифровывать; для дизайнера, который
  здесь основной читатель, хуже, чем `docs/`.
- **`wiki/`** — обещает вики (гиперссылки, оглавление, поиск), которой здесь нет.
- **Симлинк `knowledge/ → docs/`** — две правды о том, где лежит файл: ровно то, от чего
  уходили в ADR-0001. Пути в документах и в коде разъехались бы.
