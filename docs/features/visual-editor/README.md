# Visual Editor — бесплатные правки текста и фото прямо на сайте

> Назначение: инструменты, которыми клиент сам меняет текст и фото на своём сайте, **не через чат
> и не тратя кредитов** («manual edits, hosting, and publishing never use credits» — KB DreamHost,
> подтверждено дизайнером 13.09.2026). Обновлено: 30.09.2026.
> Figma: борд шелла `31280:85401` (страница «Design 2.0»; тулбар `31280:86548`, нижняя панель
> `31280:115372`), набросок окна замены фото «Images Editor» `31384:21963`; медиатека — борды
> `23383:32801` / `25812:140180` / `22926:21849` / `22926:26659`, выделение `23618:19852`
> (спека — `media-library-spec.md` рядом). Всё снято 30.09.2026.
> Код: `prototype/src/modules/editor/` (сессия, панель, хосты, оверлей, окно Image, медиа),
> `prototype/src/modules/preview/content.ts` + `site-parts.tsx` (ключи контента и хосты сайта),
> `World.siteEdits` в `prototype/src/state/world.ts`.
> Эталон логики: `docs/audits/lovable-visual-edits-teardown.md` (запись Lovable, 22 с, покадрово).

## 1. Что это и зачем

До 30.09.2026 в тулбаре канваса стояла мёртвая надпись «Visual Editor» (Glass-пилюля без кнопки и
без режима). Дизайнер снял и надпись, и режим как отдельную поверхность и заказал панель «как у
Lovable»: инструменты стоят **внизу превью, поверх сайта**, правки бесплатны, дизайн и анимации —
наши Liquid Glass. Отличие от Lovable, названное им прямо: в нашем режиме правятся **и текст, и
фото**; кнопок меньше (две против шести).

Две дорожки, честно разделённые (Hostinger — единственный конкурент, который их называет по
отдельности; Lovable маскирует платный Select среди бесплатных инструментов):

- **Edit** («T в рамке») — бесплатная: каретка в тексте одним кликом, «Replace photo» на фото,
  окно Image. Копится пачкой и применяется кнопкой **Save**: +1 к «Publish changes», кредиты не
  трогаются, свечение не зажигается, в чате тишина (дизайнер: «согласен»).
- **Select** (курсор с лучами) — дорожка ИИ: выделить элемент и задать про него вопрос в чат
  (дизайнер: «нажать на что-то и задать контекст чату»). Имя элемента — человеческое («Heading»,
  «Photo», «Dish name»), не тег `h1`/`div`, как у Lovable.

## 2. Анатомия / геометрия

**Панель инструментов (Edit bar)** — борд `31280:115372`, читан Plugin API: 78 × 42, заливка
`rgba(31,31,31,.67)`, backdrop blur **32 → у нас 16** (правило: больше ~16 в Chrome хуже, замер
26.08.2026; поднято дизайнеру), рим — линейный градиент 24 % → 4 % → 12 % белого (наш рим стекла),
r16, тень `0 8 32 rgba(0,0,0,.33)`, паддинг 4, две кнопки 32 (контейнер r8, глиф 24) через 4.
Стоит по центру канваса, низ на 29 px выше нижней кромки (борд: фрейм на y 1095 в кадре 1166).
Активный инструмент — синий диск `--action` #1587ff r8, который **вырастает** из центра глифа
(`editToolOn`, пружина `SPRING`), не фейд как у Lovable. Пока есть история правок, пилюля растёт
(`layout` на `EDIT_BAR_SPRING` .5 / .18) в
`[●T] · N changes · ↶ · ↷ | Clear · Save` — сегмент приходит тактом позже (`editBarSegment`),
вторая кнопка на это время складывается (Lovable прячет остальные инструменты так же).
Вход панели — снизу на 12 px, .96 → 1 (`editBarIn`), уход 140 мс плоско; под reduce — фейды.
Глифы — векторы борда (`modules/editor/icons.tsx`; Undo/Redo дорисованы в тот же бокс 24 / штрих 1.5).

**Рамки** (`EditOverlay.tsx`) — ОДИН оверлей внутри скролл-контента страницы, 4 px снаружи бокса
элемента, r8: ховер `1px rgb(21 135 255 / .55)` (появляется за 120 мс), выделение
`1.5px --action`; у Select над рамкой плашка `--action` 22 px с именем элемента. При входе в режим
все цели вспыхивают по одной с шагом 40 мс и гаснут за 0,9 с («показ» — новичок видит, что можно
трогать). Только opacity, ничего не двигается и не сдвигает вёрстку сайта.

**Фото в режиме** — по ховеру стеклянная пилюля **Replace photo** (36, r999, `liquid-glass`) по
центру фото; клик открывает окно Image.

**Окно Image** (`ImagePanel.tsx`) — набросок `31384:21963` («Images Editor») + скриншот живого
редактора (30.09.2026): 320, стекло `rgba(31,31,31,.7)` под blur 16 (борд 40), рим 8 %, r24, тень
`0 8 72 / .5`; тайтл «Image» Gilroy Bold 20 (pt 19 / pb 16), ✕ 32 справа; сегмент **Fit | Fill**
(трек `rgba(9,9,11,.32)` r12 p4, сиденье 32 % белого r10 h32 едет `transform` на `segmentedPill`);
картинка 288 × 256 r8 на шахматке, строук `#33333a`, AI-кнопка 40 r10 в углу; **со скриншота
живого редактора** — поля ↔ W (только чтение: ширина идёт за макетом) и ↕ H px, ползунок Opacity
0–100 в `--action`; две контурные кнопки 140 × 40 r8 (рим 24 %) **Upload File · From Library** и
**Generate via Prompt** 288 × 40 r12 `#33333a` под римом 2 px `#be59ff` (борд гасит подпись до
33 % — у нас белая: работающий контрол не рисуется выключенным; спрошено). Popover рядом с фото
(справа, если есть место, иначе слева; сверху вровень; не накрывает панель инструментов — 88 px
запаса), Panel Arrival из стороны, обращённой к фото.

**Тулбар канваса** — борд `31280:86548`: слева пусто; одна пилюля 360 × 40 r10 по центру
(перезагрузка 32 · имя страницы 15 Semibold без шеврона — клик открывает меню страниц · группа
h36 r12: девайс 32 | делитель 1 × 32 8 % | «открыть в новой вкладке» 32); справа только Publish
36. Кредиты убраны в меню аккаунта (⚠️ против вывода аудита №6, см. §6). Девайсов три: ПК → планшет
768 × 1024 → телефон 390 × 844, иконка = текущий. «↗» открывает `?view=site&path=…` — голый сайт на
всю вкладку (стейджинг), `Root.tsx`.

## 3. Состояния

| Состояние | Где | Замечание |
|---|---|---|
| Нет сайта (бриф, план, билд) | панели нет | правило «контрол без дела отсутствует, а не мёртв» |
| Нарисованный демо-сайт (synco, meridian, still) | панели нет | у рисунка нечего редактировать; спрошено, прятать ли |
| Полка сайтов открыта | панель и тулбар уходят вместе | `surface === 'sites'` |
| Покой: два инструмента | 78 × 42 | |
| Edit включён, правок нет | синий диск на «T», показ целей | Esc выключает режим |
| Ховер текста / фото | рамка 1 px / пилюля «Replace photo» | |
| Каретка в тексте | рамка 1,5 px; Enter, Esc и клик мимо принимают | Esc **не стирает** набранное (UX-критика: для новичка Esc = «готово»); пустой текст возвращает оригинал |
| Окно Image открыто | popover у фото | Esc / ✕ / клик мимо закрывают |
| Есть история (past или future) | `N changes · ↶ ↷ · Clear · Save` | Select спрятан; после Undo единственной правки сегмент ОСТАЁТСЯ ради Redo, Save выключен, подпись «No changes» |
| Грязная пачка | Save активен | режим нельзя покинуть иначе как Save/Clear (T и Esc инертны) |
| Save | +1 `unpublished`, `siteEdits` в мире, пачка чиста, режим остаётся | кредиты не двигаются; свечения нет; строки в чате нет |
| Clear | пачка сброшена, сайт как сохранён | |
| Select включён | диск на искре; ховер — рамка, клик — рамка + плашка «Heading» | клик по цели НЕ следует ссылке |
| Элемент выбран | чип «Heading ✕» в композере, плейсхолдер «Ask Remixer to change the selected element…», фокус в поле | отправка несёт `Message.about`, пузырь показывает чип; чип снимается |
| Смена сайта / пресет консоли / project ≠ built | сессия сброшена синхронно (`useWorld.subscribe`) | черновик другого сайта не переезжает |
| Чат работает (glow) | режим не гасится | правка возможна; спрошено |
| Мобильная рамка 390 × 844 / планшет | тот же DOM, редактируется | |
| F5 | правки на месте | «URL равен нашему снимку → снимок целиком» (`initialWorld`) |
| Загрузка фото не влезла в хранилище | жёлтая строка в окне Image «Kept for this session only…» | байты фото вне мира (`media.ts`) |
| 0 кредитов | Edit работает, Generate выключен с подписью «Needs credits — manual edits stay free» | KB: ручные правки работают при нуле |
| Не нарисовано | ошибка загрузки файла (сделано строкой); окно Image при обрезке экрана; Undo после Save (истории нет — открыто) | |

## 4. Решения

Полностью — `docs/knowledge/decisions.md` за 30.09.2026. Кратко:
- Копия Lovable по логике, дизайн наш; две кнопки вместо шести (заказ).
- Пачка правок + **Undo/Redo + Clear + Save** (заказ дизайнера дословно); один Save = одно
  «unpublished change» (как один ход ИИ); глагол **Save**, не Send (Send — слово чата).
- Слой правок поверх компилированной копии по стабильным ключам; блюдо — сущность (одно имя на
  четырёх поверхностях, включая таблицу Cloud); заголовок страницы — свой ключ, не переименовывает
  страницу.
- Байты фото — вне мира; ключ хранилища **не** поднят (дефолт не менялся — правило); восстановление
  среза дополняется отсутствующей осью.
- Оверлей рамок внутри скролл-контента, только opacity; человеческие имена вместо тегов.
- Сиденье сегмента едет `transform`, не `layoutId`: элемент с layout-проекцией внутри popover не
  давал AnimatePresence закончить выход (стекло на opacity 0 глотало клики — замер 30.09.2026).
- Generate via Prompt — единственная платная вещь в редакторе, с ценником (10 кредитов — цена чата,
  не проверенная; открыто).

## 6. Открытые вопросы

1. **Кредиты ушли из тулбара** (борд) — против вывода аудита №6 («кредиты постоянно в тулбаре,
   самая громкая жалоба на GoDaddy»). Предложено: короткая вспышка «−10» у аватара после отправки.
2. Blur 32 (панель) и 40 (окно Image) на бордах — у нас 16 по правилу Chrome.
3. Иконка девайса на борде — телефон при десктопном превью; у нас иконка = текущий девайс.
4. Подпись «Generate via Prompt» на наброске 33 % — у нас белая.
5. Цена «Generate via Prompt» — 10 кредитов взяты от чата; настоящей цены нет (KB: «генерация
   картинки стоит кредиты» без числа).
6. W/H и Opacity — со скриншота живого редактора, на наброске их нет: оставлять?
7. «Image management bar» (скрытый компонент на борде шелла) — остаток или замысел?
8. Undo после Save и выхода из режима — истории нет; «Version history» в шапке чата мёртв.
9. Нарисованные демо-сайты: панели нет — верно?
10. Правка во время работы ИИ — разрешена; и что делает следующий промпт с ручной правкой
    (у Lovable — молча перетирает; аудит §10.2 п.5).
11. Настоящие фото для демо-сайта — ждём от дизайнера (заглушки помечены).
12. Медиатека — по видео 30.09 и бордам; строится по `media-library-spec.md`.
