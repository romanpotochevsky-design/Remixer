Статус: **knowledge, не проверено против живого сайта** (прокси сессии режет photos.google.com).

Рекомендация для прототипа: взять поведение Google Photos как поведенческую модель (ховер-кружок, клик

~180 мс, кружок — fade 120 мс, бар — приход снизу как лист дока. Живой продукт всё это делает
без анимации — это баг живого, а не референс.

## 4. Как медиа попадает на сайт

**Не показано — не выдумывать.** В записи фото только просматривают (лайтбокс) и удаляют. Ни
перетаскивания на канвас, ни кнопки «Insert» нет. Единственная подсказка о назначении —
`Chat Add On` в баре выделения (и синяя `Add` в скрытом варианте): выбранные файлы **прикрепляются к
чату** — и дальше правку делает AI. То есть библиотека это хранилище ассетов сайта, а не
«вставщик». Для нашего Visual Editor путь «Replace photo → Image from Library» (окно Image,
борд 31384:21963) — отдельный вход в ту же библиотеку в режиме одиночного выбора, в записи его нет.

## 5. Модель взаимодействия для прототипа (на одну страницу)

**Где стоит.** В шелле 2026 рейл **справа** (56), чат слева (432). Панель `Website media` —
поверхность **над канвасом у его правой кромки**, примыкая к рейлу (зеркально живому: live-панель
стоит у левого рейла): `right: 56 + 8`, `top: 52 + 8`, ширина **480** (борд), высота до низа канваса
− 8, r16, Gray/850, рамка Gray/800. Канвас **не сужается** (в live сужается — но у нас превью и так
масштабируется; сужение перезапускает container queries, дорого) — панель лежит поверх, как панель
Publish. Вход — тем же Panel Arrival, что панель Publish (стекло из кнопки рейла .94 → 1, контент на
такт позже, блик в тоне кнопки), уход 140 мс. Кнопка рейла «Media» — плитка selected пока панель
открыта (Rail Flood от точки клика). Открыта — вторая кнопка Publish/Account её закрывает (одно
плавающее окно у правой кромки).

**Входы.** (1) Кнопка рейла — библиотека в режиме **manage** (мультивыбор, удаление, add-to-chat).
(2) `Image from Library` из окна Image в Visual Editor — режим **pick**: та же панель, но выбор
одиночный, бар внизу «Use photo» вместо корзины, Esc/✕ возвращает в окно Image. (3) `+` композера →
`Attach File` — не трогаем.

**Состояния.** `closed` → `open{tab: image|video|audio|docs}`; в `image`: `browsing` → `selecting{ids}`
(bar) → `confirmDelete` → `browsing`; `viewing{id}` (лайтбокс). Пустая вкладка — центрированная
строка «No audio files found» / «No documents found» / «No videos yet» / «No images yet» (последние
две — наши, борд не рисует) + под ней тональная `Upload media` (наше предложение, спросить).

**Плитка.** Квадрат в 3 колонки (GRID, зазор 8 по записи; 4 борда — вопрос), фон Gray/750 под
не-заполняющими картинками (логотипы), r2. Ховер: кружок 20 в (8,8) fade 120 мс. Клик по фото →
лайтбокс; клик по кружку → selected (spring 180 мс: фото → inset 14/12, r8; подложка Gray/750; синий
кружок). В `selecting` клик по любой плитке — toggle; shift — диапазон; Esc — сброс; клик по `˅` у
«N Selected» — меню `Select all / Deselect all` (наше — спросить).

**Бар.** 464×72 Gray/750/Gray/700, r16, тень 0/8/32 50 %, инсет 8/9, приезжает снизу как лист
(`sheet` 240 мс, spring), футер под ним гасится. «N Selected ˅» · Chat Add On · Delete. Delete →
диалог (наш `Confirm` как у «Disconnect…?»: скрим 70 %, стекло .92 → 1, 200 мс): «Delete N images?» /
«This action cannot be undone.» / `Cancel` · `Delete` красная. После удаления плитки **уезжают**
(layout spring), бар считает до «0 Selected» и через 200 мс складывается в футер.

**Лайтбокс.** Скрим 85 %, фото `max 100vh−160`, центр окна, вход .96 → 1 + fade 180 мс, ✕ 32 в
правом-верхнем углу окна (инсет 16), клик по скриму / Esc закрывает; стрелки ‹ › между фото (наше —
спросить).

**Upload.** `Upload Media` → системный пикер (`<input type=file multiple accept=image/*,video/*,
audio/*,.pdf,.doc,.docx>`); загруженное встаёт **первой** плиткой с прогресс-кольцом (наше). Байты —
в `modules/editor/media.ts`, не в мире (урок Visual Editor). Drag-and-drop файла на панель — зона
«Drop to upload» (наше).

**Клавиатура.** Tab по вкладкам (roving), стрелки по сетке, Space/Enter — выбор/просмотр, Delete —
удалить выбранное (с диалогом), Esc — сброс выделения → закрыть лайтбокс → закрыть панель.

**Данные.** Ось `world.media[]` (id, kind, name, size, duration, added, url) в `SITE_AXES`; демо —
фото демо-сайта из `modules/preview/photos/` + 2 видео + пусто в Audio/Docs (или 3+2 строки борда).

## 6. Открытые вопросы дизайнеру

1. **Ширина**: live 512, борд 480 — какую? Наш шелл: панель над канвасом у правого рейла или канвас
   сужается, как в live?
2. **Вкладки**: пилюли 36 — нелегальный размер (32/40/48); зазор 8 (борд) или 16 (live)?
3. **Сетка**: квадраты с зазором 8 (live) или 152×142 с зазором 4 (борд)?
4. **Лейбл бара**: «1 Select» (борд) vs «1 Selected» (live) — предлагаю «1 selected» по Google
   Photos. Что в меню `˅`?
5. **`‹ ›` в шапке** (Unfold More) — раскрывает панель шире? И что открывает `Website media ˅`
   (переключение библиотек? стоковые фото?).
6. **Пустые состояния** борд не рисует; текст live «No audio files found» / «No documents found»;
   Image/Video пустые — «No images yet»? Ставить кнопку загрузки в пустое состояние?
7. **Chat Add On** — прикрепить к композеру чата? Одиночный «pick» для `Image from Library` — тот
   же компонент с кнопкой «Use photo»?
8. **Анимации**: live делает всё за 1 кадр (лайтбокс, выделение, смена вкладок, удаление) — делаем по
   Google Photos (сжатие ~180 мс) в Liquid Glass? Диалог удаления — нашим `Confirm`?
9. **Лайтбокс**: стрелки prev/next, имя файла, «Use on page»? Или только просмотр?
10. **`Generate ✦`** — генерация изображения в библиотеку? Цена в кредитах?
11. **Скрытый ряд `Search + sorting`** — вернётся при большом количестве файлов?
12. **Гарнитуры**: мета строк Audio/Docs набрана Roboto — заменить на Proxima Nova?
13. **Плитка-видео**: длительность Gilroy Medium 12 в углу — в live её нет; оставляем борд?
14. **Кнопка `Upload Media`**: иконка ⤒ (Image/Video) vs «+» (Audio/Docs), футер с волоском vs без —
    случайность или намерение?
15. Старый компонент `Image` (квадратный чекбокс с блюром, градиент, имя файла) в бордах ещё стоит
    на большинстве плиток — считать устаревшим?
