## Вход в сессию — строго в этом порядке

1. `git fetch origin --prune`
2. `git checkout -B claude/remixer-connect-domain-flow-4fpgqc origin/claude/remixer-connect-domain-flow-4fpgqc`
   — вся работа лежит там.
   ⚠️ Контейнеру сессии может быть назначена ДРУГАЯ ветка, и на ней этой работы нет; зеркало
   `claude/remixer-connect-domain-flow-utiay8` отстаёт — **в него не пушить никогда**.
   ⚠️ **В ЭТОЙ ВЕТКЕ РАБОТАЕТ НЕ ОДНА СЕССИЯ.** 15.09–16.09.2026 две сессии писали в неё по очереди:
   параллельная запушила коммит поверх моего, пока мой контейнер перезапускался, а на
   следующий день — наоборот (пуш отклонён, поставлено поверх ребейзом своего непушенного
   коммита). Ничего не потерялось —
   но отсюда правило: `git fetch origin --prune` **перед каждым пушем**, а не только на
   входе, и прежде чем считать своё дерево актуальным — посмотреть, что лежит на remote
   (`git log --oneline HEAD..origin/<ветка>`). Своё поверх чужого ставить только `--ff-only`
   или мержем, никогда force.
3. Только после чекаута читать `CLAUDE.md` целиком и `docs/knowledge/decisions.md`
   (что уже принято и что уже ОТКЛОНЕНО — смотреть ДО того, как что-то предлагать).
4. Журнал последних сессий: `docs/sessions/2026-09-13b--connect-domain-for-product-owners.md`
   (раунды 1–18; раунды 13–18 — последняя работа).

## Чего не делать

- Не возвращать в панель Publish мгновенное появление/исчезновение блоков и «четыре карточки
  подключения по очереди» — дизайнер снял прыжок на видео (16.09.2026); каждый новый блок панели
  идёт через `Reveal` с отступом внутри клипа, а не с `mt-*` на себе. И не расширять анимацию
  `height` за пределы панели без замера: три условия — `design-system.md` §9 п. 9.
- Не возвращать: движок флоу (`flows.ts`, `FlowPlayer`), скелетон загрузки превью, блик по
  кромке панели Publish, иридесцентное свечение резайзера, описания под доменами, «· Free» на
  кнопке Publish, «Keep editing» и ссылку назад в окно доменов в панели, вторую ссылку в окне,
  стрелку схлопывания превью в тулбаре канваса.
- Цвета Figma читать ТОЛЬКО `get_variable_defs` в ТЁМНОЙ теме: референс-код резолвит светлую
  (`Background/Blue/Default` печатается `#0073ec`, а в тёмной это `#1587ff` = наш `--action`).
- Штрих Figma сидит ВНУТРИ геометрии: рамки — `inset box-shadow`, а где внутри есть дуги —
  «вытянуть ребёнка» (`-mx-px`). Двойной бордер по этой причине ловили уже трижды.
- Размер фрейма иконки — не размер глифа: мерить чернила по рендеру (ловились трижды).
- Перформанс-контракт: покадрово только `transform` и `opacity`; покадровый repaint разрешён
  ровно в трёх местах (`.thinking`, строка работы карточки генерации, рисующееся кольцо).
