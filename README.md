# Remixer — UI/UX

Рабочий репозиторий UI/UX-проекта **Remixer** (AI Website Builder от DreamHost).
Здесь живёт всё, что нельзя терять между сессиями: база знаний по конкурентам,
исследования, дизайн-хендоффы и живой кликабельный прототип интерфейса.

| Папка | Что внутри |
|---|---|
| `docs/INDEX.md` | Карта базы знаний — что где лежит и когда актуализировано (читать первым) |
| `docs/competitors/` | Конкурентный аудит Q3 2026, критика аудита, разборы живых Lovable и Bolt |
| `docs/design-system/` | Замеры дизайн-токенов конкурентов, спека Remixer glow |
| `docs/features/` | Знания по фичам: домены (ресёрч поиска и подключения, дизайн-хендофф → Figma), publish |
| `docs/archive/` | Сырьё исследований: досье конкурентов, UX-линзы, фактчек |
| `prototype/` | Кликабельный прототип билдера: React + Vite, без бэкенда, данные захардкожены |
| `maintenance-page/` | Готовая maintenance-страница (самодостаточный HTML + .htaccess с 503) |
| `CLAUDE.md` | Память проекта — контекст, факты и правила, которые Claude читает в каждой сессии |

## Прототип

```bash
cd prototype
npm install
npm run dev
```
