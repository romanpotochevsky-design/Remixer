# Remixer — UI/UX

Рабочий репозиторий UI/UX-проекта **Remixer** (AI Website Builder от DreamHost).
Здесь живёт всё, что нельзя терять между сессиями: база знаний по конкурентам,
исследования, дизайн-хендоффы и живой кликабельный прототип интерфейса.

Документация разложена по темам. **В каждой тематической папке `README.md` написан
как брифинг «поднять работу с нуля»**: где лежит работа, что уже решено, какие факты
проверены, какие цифры отгружать нельзя и что осталось открытым вопросом.

| Папка | Что внутри |
|---|---|
| `docs/Remixer Connect domain/` | Домены целиком: поиск, покупка, подключение своего, трансфер, состояния до «сайт отвечает». Аудит бордов, ресёрч, замеры корзины, кадры обеих цепочек |
| `docs/Remixer Publish/` | Панель Publish: хром, счётчик изменений, поле адреса, строка домена. Собранная спека с замерами |
| `docs/Remixer Competitive audit/` | Конкурентный аудит Q3 2026 и его критика, замеры токенов с живых сайтов, разборы Lovable и Bolt, сырьё исследований |
| `docs/Remixer Shell/` | Оболочка билдера: спецификация фирменного свечения превью |
| `prototype/` | Кликабельный прототип билдера: React + Vite, без бэкенда, данные захардкожены |
| `maintenance-page/` | Готовая maintenance-страница (самодостаточный HTML + .htaccess с 503) |
| `CLAUDE.md` | Память проекта — контекст, факты и правила, которые Claude читает в каждой сессии |

## Прототип

```bash
cd prototype
npm install
npm run dev
```
