# Remixer — UI/UX

Рабочий репозиторий UI/UX-проекта **Remixer** (AI Website Builder от DreamHost): база
знаний проекта плюс живой кликабельный прототип интерфейса. Контейнер рабочей сессии
умирает — репозиторий остаётся, поэтому здесь лежит всё, что нельзя терять между
сессиями: правила работы, проверенные факты, принятые решения, конкурентные аудиты,
знание по фичам, дизайн-система и код прототипа.

## 📍 Карта — [`docs/INDEX.md`](docs/INDEX.md)

**Читать первым.** Индекс — единственная карта базы знаний: строка на каждый документ,
что внутри и на какую дату верно его содержание. Здесь этот список не дублируется
намеренно: две карты расходятся за один день.

Новой сессии: [`docs/global/AGREEMENTS.md`](docs/global/AGREEMENTS.md) (правила работы) →
[`docs/global/SESSIONS.md`](docs/global/SESSIONS.md) (где стоит работа) →
[`docs/product/FACTS.md`](docs/product/FACTS.md) (все числа проекта, по ID).

## Что где

| Путь | Что внутри |
|---|---|
| `docs/global/` | Как мы работаем: соглашения, плейбуки процедур, журнал сессий |
| `docs/product/` | Регистр фактов (единственное место, где живёт число), правила языка продукта, позиционирование |
| `docs/decisions/` | Журнал сквозных решений проекта (ADR) — что решили, почему, что отклонили |
| `docs/competitors/` | Конкуренты: досье по компаниям, большие аудиты в `audits/`, наряд на слепые зоны |
| `docs/design-system/` | Визуальный язык: цвет и типографика, поверхности, моушен, спеки эффектов, замеры чужих токенов |
| `docs/features/` | Знание по областям продукта: реестр фич + домены, публикация |
| `docs/archive/` | Сырьё исследований. Не курировано, отсюда не цитируем |
| `prototype/` | Кликабельный прототип билдера: React + Vite + TypeScript, без бэкенда, данные захардкожены |
| `prototype/docs/` | Инженерная память прототипа: архитектура, кадровый бюджет, чат, шрифты |
| `maintenance-page/` | Готовая maintenance-страница (самодостаточный HTML + `.htaccess` с 503) |
| `CLAUDE.md` | Правила сессии и карта для Claude — роли, что читать, чего не делать |

## Прототип

```bash
cd prototype
npm install
npm run dev
```

`npm run build` — ворота качества, должно быть зелено. `npm run artifact` собирает один
самодостаточный HTML для публикации. Постоянные ссылки на артефакты (прототип и
HTML-аудит) — в [`docs/INDEX.md`](docs/INDEX.md), раздел «Постоянные ссылки»; правило
«обновлять, а не публиковать заново» — в
[`docs/global/PLAYBOOKS.md`](docs/global/PLAYBOOKS.md), плейбук 5.
