# Remixer — UI/UX

Рабочий репозиторий UI/UX-проекта **Remixer** (AI Website Builder от DreamHost).
Здесь живёт всё, что нельзя терять между сессиями: база знаний по конкурентам,
исследования, дизайн-хендоффы и живой кликабельный прототип интерфейса.

**Начинать с [`docs/README.md`](docs/README.md)** — там карта базы знаний и правило,
куда класть новый материал.

| Папка | Что внутри |
|---|---|
| `docs/README.md` | Карта базы знаний: что где лежит и куда класть новое |
| `docs/knowledge/` | Долгоживущая правда проекта: факты о продукте (со статусом и датой), дизайн-система, карта конкурентов, журнал решений, словарь и правила копирайта |
| `docs/features/` | По папке на фича-область — своя база знаний у каждой: `builder-shell/`, `domains/`, `home-page/` |
| `docs/sessions/` | Журнал всех сессий: как его вести, индекс сессий, запись по каждой |
| `docs/audits/` | Конкурентный аудит Q3 2026, критика аудита, замеры дизайн-токенов, разборы живых Lovable и Bolt |
| `docs/research/` | Сырьё исследований: досье конкурентов, UX-линзы, фактчек, ресёрч поиска доменов |
| `docs/handoff/` | Дизайн-хендоффы (домен-флоу + publish-панель → Figma) и инженерная спека Remixer glow |
| `prototype/` | Кликабельный прототип билдера: React + Vite, без бэкенда, данные захардкожены |
| `maintenance-page/` | Готовая maintenance-страница (самодостаточный HTML + .htaccess с 503) |
| `CLAUDE.md` | Память проекта — контекст, факты и правила, которые Claude читает в каждой сессии |

## Прототип

```bash
cd prototype
npm install
npm run dev
```
