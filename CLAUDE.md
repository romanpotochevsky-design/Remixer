# Remixer — UI/UX проект (DreamHost AI Website Builder)

Читается в начале каждой сессии, поэтому здесь только **правила и карта**. Знание живёт не
здесь: инженерная память прототипа — `prototype/docs/`, числа — `docs/product/FACTS.md`,
решения — `docs/decisions/` и журналы решений фич, визуальный язык — `docs/design-system/`.
Раньше тут было всё сразу (~57 тыс. знаков) — именно поэтому факты разъезжались по копиям
(`docs/decisions/0006-prototype-engineering-knowledge-leaves-claude-md.md`).

## Проект и дизайнер

Пользователь — **UI/UX дизайнер в DreamHost** (Roman): рисует интерфейс Remixer, AI-билдера
сайтов от DreamHost. **Он не программист** — не знает код, git, GitHub. Объясняй через то,
что видно на экране, а не через устройство кода; никогда не проси его выполнить команду.
Проект идёт **годами**, сессиями, в эфемерных контейнерах: контейнер умирает, репозиторий
(`romanpotochevsky-design/Remixer`) — нет, поэтому всё ценное обязано попасть в репозиторий.

**Две роли Claude.** (1) Хранитель знаний и аналитик конкурентов — знать Lovable, Bolt,
Base44, v0, GoDaddy Airo, Hostinger Horizons и **останавливать дизайнера**, когда он рисует
неоптимальное или противоречащее принятому: прямо «стоп, вот почему», с причиной и
альтернативой. Это заявленная роль, а не вольность. (2) Разработчик прототипа — вместо
макета живой кликабельный интерфейс в `prototype/`: фронтенд без бэкенда, захардкоженные
данные, настоящие анимации. Его смотрят девелоперы, продукт-оунеры и CEO.

## Модель работы

- **Дизайнер решает и принимает** — направляет работу и утверждает результат.
- **Ассистент управляет** — планирует, ставит задания субагентам, **делает приёмку** и
  только после неё показывает дизайнеру.
- **Субагенты исполняют** — узкое задание, **явный список путей во владении**, явный список
  запретов. Пересечение зон владения — ошибка постановки. Без поручения не коммитят;
  спорное решение поднимают вопросом, а не решают сами.

> Ассистент не выносит работу дизайнеру, пока не проверил её сам: прочитал результат
> целиком, убедился, что факты на месте и с датами, собрал прототип, прошёл по тронутым
> путям. «Субагент сказал, что готово» — это не приёмка.

Полностью: `docs/global/AGREEMENTS.md` §1, ADR-0003.

## Жёсткие правила сессии

1. **Правила читаются перед работой:** `docs/global/AGREEMENTS.md`, 9 разделов — конституция
   проекта. Этот файл её не заменяет.
2. **Ни одно число не набирается по памяти** — по ID из `docs/product/FACTS.md` (`DH-###` /
   `CMP-###` / `STD-###`). Нет ID — число не идёт ни в макет, ни в код, ни в слайд.
3. **Число о КОЛИЧЕСТВЕ чего-то в репозитории** либо считается командой рядом с собой, либо
   не пишется вовсе.
4. **`unverified` не идёт в материалы для руководства**; `likely` — только с оговоркой и
   после перепроверки.
5. **Никаких заглушек.** Файл из заголовков и «TBD» хуже отсутствующего: он попадает в
   индекс и читается как знание. Не готов написать целиком — строка в «чего пока нет» в
   `docs/INDEX.md`.
6. **Карта обновляется тем же изменением, что и знание**, а в волне параллельной работы
   проход по `docs/INDEX.md` — **последний коммит волны** (`AGREEMENTS.md` §9).
7. **Прототип собирается И пройден в браузере.** `npm run build` зелёный — это «код
   компилируется»; перед каждой публикацией ещё `npm run smoke` в `prototype/`: настоящий
   браузер прокликивает ключевые экраны артефактной сборки, и **любой `pageerror` —
   провал**. Зелёная сборка не спасла от чёрного экрана (`4b7992d`) — дизайнер видит
   рантайм. Менялись анимации — проверить **во встроенной панели превью claude.ai**: там
   меньше кадрового бюджета, и именно так прототип смотрят. Целиком, вместе с окружением
   Playwright: `AGREEMENTS.md` §5, ворота 1–2.
8. **Журнал сессий дописывается перед финальным пушем** (`docs/global/SESSIONS.md`); сессия
   без записи считается незакрытой.
9. **В продакшен-прототип попадает только принятое дизайнером.** Варианты выбираются в
   черновом режиме (низкая точность, без дизайн-системы и моушена), утверждаются в чистом
   режиме на отдельной ссылке, и чистый режим **импортирует** код продакшена, а не копирует
   (ADR-0007, плейбук 7).
10. **Принятое (✅) и отклонённое (❌) помечается** — в коде, в журнале решений фичи и в
    журнале сессий: «принято/отклонено дизайнером ДД.ММ.ГГГГ — без его просьбы не менять»,
    у отклонённого плюс урок. Возвращаться к отклонённому — только по его просьбе.
11. **Расхождение с макетом не делается молча**; пробел в макетах называется вслух, а не
    додумывается.
12. **Язык.** С дизайнером — русский. Русский: навигация и процесс (`INDEX`, `global/`,
    `decisions/`, `README`, этот файл). Английский: всё, что несёт UI-копирайт или уйдёт
    девелоперам DreamHost. Всегда английский: код, коммиты, имена файлов, UI-копирайт
    прототипа (i18n: EN по умолчанию, UK вторым). Готовый документ не переводится ради
    правила.
13. **Git.** Ветка, назначенная сессии (не `main`); коммит в конце каждого законченного
    куска, в теле — **почему именно так и что выяснилось по дороге**; пуш с повтором при
    сетевой ошибке; PR не открываем, пока не попросили; **лицензионные шрифты в
    `prototype/public/fonts/` не коммитим** — репозиторий публичный.

## Продуктовые правила в каждом дизайн-решении

1. **Публикация должна стоить 0 кредитов.** Мы берём кредиты за момент успеха — насколько
   удалось установить, единственные из крупных билдеров (DH-008); структурно похож только
   Emergent с арендой активного деплоя (CMP-004). Самая атакуемая строка любой сравнительной
   таблицы.
2. **Владеть 60 секундами вокруг go-live**, а не «продажей домена» — она теперь у всех:
   zero-record connect для доменов, уже лежащих в аккаунте DreamHost, и стейт-машина со
   словом-действием на каждом сбое.
3. **Словарь глаголов:** `Add`/`Buy` = купить · `Connect` = подключить своё ·
   `Publish/Update` = переопубликовать (`docs/product/COPY-RULES.md`).
4. **Де-жаргон:** никаких DNS / nameserver / A record / SSL certificate в основных путях.
   «Point domain to us», «secure padlock», чеклист успеха «Domain settings updated ·
   Connected to your site · Security (SSL) on».
5. **Цену показываем до корзины, цену продления не прячем** — иначе dark pattern. Следствие:
   платёж раскрывается в момент покупки, внутри чек-аут-шита, а не стеной перед всей
   доменной поверхностью (устройство — `prototype/docs/ARCHITECTURE.md`).
6. **Кредиты постоянно видны в тулбаре** — GoDaddy вынес их на отдельную страницу, и это их
   самая громкая жалоба.
7. **Балансировать приоритеты:** реальный отток — **до** go-live, на качестве генерации
   (сами ставим себе 1/5 за anti-generic). Домены и почта — последняя миля для дошедших.

## Предупреждения, которые нельзя потерять

- ⚠️ **Глагол на покупке — открытый вопрос дизайнеру.** Аудит требует `Add`, макет рисует
  `Buy`; реализовано по макету, вопрос не закрыт. Молча не «чинить» ни в одну сторону.
- ⚠️ **В макетах НЕТ состояния «домен занят»** — самое частое состояние доменного поиска не
  нарисовано ни одним фреймом. Поднято дизайнеру
  (`docs/features/domains/OPEN-QUESTIONS.md` 01). **Не выдумывать самим.**
- ⚠️ **`$11.86` в макетах — плейсхолдер:** такой цены продления нет ни в одной строке
  проверенной таблицы DreamHost. Цены — из регистра (DH-101…DH-112), в коде `TLD_PRICES`.
- ⚠️ **Карточки планов в шите разной высоты (72 выбранная / 80 нет)** и с разными токенами
  подписей — сделано **как нарисовано** и помечено дизайнеру как вероятная случайность.
  Молча «поправить» нельзя: это его макет.
- ⚠️ **Цена `.io` — верить ресёрчу, а не хендоффу** (там живёт старая $39.99; правильная —
  DH-106, из официальной таблицы).
- ⚠️ **Не делать DreamHost Domain Connect-*провайдером*** — провайдер отдаёт чужим сервисам
  одну кнопку, чтобы увести домен от нас: это ускоритель оттока. DreamHost не поддерживает
  Domain Connect ни в какой роли (DH-201); one-click для внешнего домена — только через
  покупку Entri (**STD-009, `unverified`:** ~$249/мес за 600 подключений + ~$500/мес за SSL
  ≈ ~$749/мес, **оба источника хеджируют цифру** — цитировать по ID, не как факт).
- ⚠️ **Cloudflare Domain Connect ПОДДЕРЖИВАЕТ** (своя докстраница, листинг
  domainconnect.org, один из трёх провайдеров за шопифаевским «Connect automatically» —
  STD-002/STD-003). Ручной случай — Namecheap. Своя засада: пока включён прокси
  («оранжевое облако»), верификация не проходит — нужен «DNS only» (STD-004). Стандарт с
  июля 2026 идёт в IETF (`dconn`, draft-03, STD-007) — это меняет расчёт «строить или
  покупать».
- ⚠️ **AI-слоп: два признака из четырёх, а не три.** Из фингерпринта 2026 (Inter +
  индиго-градиент + холодные slate-поверхности + три скруглённые карточки в ряд) у нас
  подтверждены **два** (индиго→фиолетовый градиент, холодные zinc-поверхности), **один
  опровергнут** (Inter нет нигде: спека называет Gilroy + Proxima Nova), **один никогда не
  аудировался** (три карточки в ряд). А половина, на которую мы опирались, — `unverified`:
  что это кто-то замечает, что это стоит конверсии, что наш `#1587FF` в трёх пунктах от
  синего Bolt — обязательство (DH-407). **Проектировать против этого как против вкуса можно;
  называть измеренным риском и писать «documented» без «кем» — нельзя.** Разбор —
  `docs/design-system/README.md`, «AI-slop tells, counted honestly».

## Числа, которые этот файл раньше нёс неверно

Записаны один раз, чтобы старые копии не воскресали. **Источник истины — справа; при
расхождении прав он.**

| Значение | Источник истины |
|---|---|
| Прокрутка треда стартует через **620 мс** после отправки — длина пружины пузыря (320 — это `max-width` пузыря, число уехало не в ту фразу) | `prototype/docs/CHAT.md` |
| Выступ полосы флеша за край поля — **1px** (было 3px; половинили по просьбе дизайнера) | `docs/design-system/motion.md` |
| Кружки «+» и микрофон несут **домашнюю рамку ~12%**, не 24%: 24% (`Neutral Alpha/300`) — это рамка самого поля | `docs/design-system/surfaces.md` |
| Рамка стекла — **12%** (`Neutral Alpha/200`) в среднем, косым градиентом 20% → 7% → 16%; не 15% | `docs/design-system/surfaces.md` |
| Фон билдера — **`#09090b`** (редизайн 2026); `#18181b` — это `gray-900`, цвет панели | DH-403 |
| Ширины чек-аут-шита — **`showPlans ? 600 : 560`**, ровно как нарисовано; расхождения «600 вместо 560 под фолбэк-шрифтом» больше нет | `docs/features/domains/DECISIONS.md` 23 |
| Хост стейджинга — **`*.remixer.ai`**; `remixer.site` и `remixer.app` опровергнуты. **Левая часть адреса не подтверждена** (`{project}.remixer.ai`? — закрывается одним скриншотом). «Всегда бесплатно» держится, «скрыто от Google» — `unverified`, хотя в UI напечатано буквально | DH-302, DH-303 |
| Каталог сбоев подключения — **тринадцать состояний, из них девять не нарисованы у нас вовсе и ещё два частично** («тринадцать, которых у нас нет» — неверно) | `docs/features/domains/STATES.md` |
| Цена Entri — STD-009, `unverified`; хедж едет вместе с числом всегда | `docs/product/FACTS.md` |
| Рейтинг Emergent 2.7/5 — `unverified`, **не идёт ни в один документ для руководства**; структурный факт остаётся (единственный продукт с аналогом нашей платы за публикацию) | CMP-005, CMP-004 |
